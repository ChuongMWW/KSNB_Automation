# KSNB_Automation

Website tài liệu quy trình KSNB dạng static HTML, có hỗ trợ chỉnh sửa inline và auto-sync cục bộ qua `live_sync_server.py`.

## Deploy

Project đã được chuẩn bị để deploy trực tiếp lên Vercel. Xem [DEPLOY_VERCEL.md](DEPLOY_VERCEL.md).

## Local Auto-Sync

Chạy `live_sync_server.py` trên máy Windows để chức năng **Lưu vào Code** ghi HTML trở lại repository local.
